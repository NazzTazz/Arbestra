# Politique de sécurité / Security Policy

## Versions suivies / Supported versions

Seule la version déployée sur l'alpha (`main`) reçoit des correctifs de sécurité.
Only the version deployed on the alpha (`main`) receives security fixes.

## Signaler une faille / Reporting a vulnerability

**Ne crée pas d'issue publique.** Utilise le signalement privé de GitHub : onglet **Security** du dépôt, puis **Report a vulnerability** (<https://github.com/NazzTazz/Arbestra/security/advisories/new>). Seul le mainteneur voit le rapport ; nous en discutons en privé jusqu'au correctif, puis l'avis peut être publié.

**Do not open a public issue.** Use GitHub's private vulnerability reporting: the repository's **Security** tab, then **Report a vulnerability** (<https://github.com/NazzTazz/Arbestra/security/advisories/new>). Only the maintainer sees the report; we discuss it privately until a fix ships, then the advisory can be published.

Décris le problème, son impact et comment le reproduire. N'attaque pas les serveurs de l'alpha ni les comptes d'autres joueurs pour le démontrer : un environnement local (voir [CONTRIBUTING.md](CONTRIBUTING.md)) suffit.
